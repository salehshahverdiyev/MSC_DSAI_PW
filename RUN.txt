T10 - Implementing a Queue
Javidan Hajizada and Saleh Shahverdiyev, UFAZ M1; Professor Pavel.

We investigate queue work, operation time and memory in BFS on synthetic and
real graphs, including frontier growth and resizing spikes. Four queue
implementations are available: shifting array, linked list, circular doubling,
and incremental circular resizing. Final statistical timing/memory experiments
remain a protocol task.

Use Python 3.10+ and the standard library (tested with CPython 3.13.1).
Run from the repository root:
  python -m t10.demo
  python -m unittest discover -s t10/tests -v
  python -m t10.demo --dataset data/raw/ssumlinks.txt
  python -m t10.real_demo --dataset brainlinks.dat --edges 40
If the Windows python alias fails, this PC has a local portable runtime:
  ./.local-tools/python/python.exe -m t10.demo
Use that executable in place of python in the other commands too.

Dataset: C. elegans summed neural links. Download once if absent; no automatic
network requests occur during execution. Keep data/raw/ssumlinks.txt local:
https://www.quantware.ups-tlse.fr/QWLIB/wormgooglematrix/ssumlinks.txt
PowerShell, from the repository root (does not overwrite an existing file):
  New-Item -ItemType Directory -Force data/raw | Out-Null
  if (!(Test-Path data/raw/ssumlinks.txt)) { Invoke-WebRequest -Uri https://www.quantware.ups-tlse.fr/QWLIB/wormgooglematrix/ssumlinks.txt -OutFile data/raw/ssumlinks.txt -TimeoutSec 40 }

Verified file: 279 vertices, 2990 directed edges; 275 reachable from source 0.
Columns i j weight mean j -> i, with 1-based IDs mapped to 0-based IDs.
Positive weights become unweighted edges: BFS measures hops, not weight sums.

Files:
  t10/queues.py - four queue implementations, common interface and work counters.
  t10/graph.py  - path/star/tree/grid generators and local load_worm loader.
  t10/bfs.py    - one BFS for every queue, distances and optional diagnostics.
  t10/demo.py   - small hand-checked demonstrations and optional real graph.
  t10/tests/   - deterministic FIFO, independent distances and loader checks.
Counters report executed shifts/copies, resize events, occupancy and capacities;
they are not timing or memory benchmarks. Local Markdown under docs/ contains
checkpoint materials, hypotheses, a draft protocol and incremental design.
Markdown and private study notes remain local and are excluded from Git.

The real-data demo uses 40 real Brainlinks vertex IDs as labels for transformed
Path, Star, Binary tree, and Grid 5x8 graph shapes, then also compares the
original bounded Brainlinks edge sample. It measures BFS wall time, peak traced
Python memory, queue work counters, and writes one dependency-free SVG
visualization per graph into
`bfs_visualizations/` by default. Use `--output-dir` to change that directory.
The measurements are illustrative for the selected sample, not a full-scale
benchmark. BFS uses O(V + E) time and O(V) auxiliary space; adjacency storage
is O(V + E).
